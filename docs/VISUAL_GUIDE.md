# Visual Guide

Reference/microservice repos should use a small consistent visual pack.

Recommended pattern:

1. **Architecture flow** — what enters, which responsibility layers run, what exits.
2. **Boundary diagram** — what this public repo owns versus what private Nexus keeps.
3. **Evidence/test image** — optional, only when there is a concrete test story worth visualizing.

Included here:

- `diagrams/memory_kernel_flow.svg`
- `diagrams/memory_kernel_layers.svg`

Visual style should match the Nexus engineering portfolio: dark technical background, clean cyan/blue accents, restrained labels, no "vibe-code" aesthetic.
